# 界面素材

产品介绍页 `../index.html` 直接读取本目录，无需额外构建。演示视频按**「先建习惯」的使用路径**分成 6 段，一段一个卖点；页面左侧播放、右侧同步显示卖点，点缩略图切换。

## 演示片段

| 文件 | 画面 | 时长 | 卖点 |
| --- | --- | --- | --- |
| `clip-01-create.mp4` | 新建习惯：模板、18 色、40 图标 → 新气泡出现 | 21.9 秒 | 建一个习惯，不用填表 |
| `clip-02-checkin.mp4` | 气泡打卡：戳破气泡 → 完美的一天彩纸 | 15.9 秒 | 两次点击，一天记完了 |
| `clip-03-calendar.mp4` | 点日期 → 2026.11 月历 → 切到昨天补记 → 回今天 | 8.4 秒 | 忘了的那天，也能补记 |
| `clip-04-stats.mp4` | 单习惯详情（月历、年度点阵）→ 统计页 | 15.9 秒 | 把日子变成看得见的形状 |
| `clip-05-settings.mp4` | 设置页浅色 → 深色 → 回列表 | 13.5 秒 | 样子随你，数据不变 |
| `clip-06-collection.mp4` | 收藏图鉴（普通／稀有／史诗）→ 掉落物 | 11.3 秒 | 一点乐趣，但不打扰 |

`poster-01.jpg` ~ `poster-06.jpg` 是从各片段里抽出的封面帧，用作视频封面与切换缩略图。缺哪段，页面就不显示哪段的播放，不会出现死链。

**规格**：竖屏 592×1280、H.264 MP4、六段合计约 4.3MB。不要用 Git LFS 托管视频，GitHub Pages 不会渲染 LFS 指针文件。素材为真实使用画面，其中的习惯名称与统计数字不是凭据，但公开前仍可自行决定要不要打码。
