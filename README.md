# 习惯气泡 · Habit Bubbles

一个装在手机桌面上的**本地优先习惯追踪 PWA**。好习惯点一下戳破气泡，坏习惯如实记一笔；所有记录只留在这台设备里，不注册、不联网、不上传。

> 本仓库是**作品集 / 学习用公开版**：只含纯本地版源码与项目文档，不含账号体系、云端备份、访问凭据或任何真实用户数据。

## 一眼看懂

- **打卡够快**：气泡画布 / 极简列表两种形式，两次点击以内完成一次记录；创建习惯是「做选择」而不是「填表单」。
- **诚实记录**：好习惯每天记完成；坏习惯是中性账本，没发生不用记，发生点一下，不做道德评判。
- **看得见的积累**：日 / 周 / 月 / 年四种粒度、全局与单习惯两个视角，含双向柱状图、圆圈月历、年度点阵。
- **一点乐趣**：掉落物有重力与体感互动、收藏室、完美一天的小庆祝；每天可撤销一次，防刷。
- **数据自主**：本地存储、JSON / CSV 导出、从文件导入、断网可用、可添加到桌面。

## 本地运行

```bash
cd app
npm install
npm run dev      # 开发预览
npm run build    # 生产构建
npm run smoke    # 核心规则自检
```

> 公开版对资源做了精简：仓库里只保留 SVG 图标，位图图标未随源码分发；因此 PWA 的桌面图标能力在本地运行时可用，完整图标集需自行补齐。

## 几个设计取舍

- 不做补签卡、连续天数护盾、提醒推送、社交排行、账号体系 —— **记录是为了复盘，不是催自己**。
- 好习惯上限 6、坏习惯 3：刻意设上限，逐个击破。
- 写进文档的非功能要求（对比度、减少动效、离线可用）都有对应的验收动作。
- 收藏品概率：完美一天只提升普通收藏的出现概率，稀有与史诗只在阶段性里程碑日提升。

## 在线预览

仓库里的 `.html` 文件在 GitHub 文件页**只显示源码，不会渲染成页面**（GitHub 只渲染 Markdown、图片、PDF、CSV、Notebook、Mermaid 等格式）。想让别人点链接直接看到效果，开启 GitHub Pages：

**Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`** → 分支选 `main`、目录选 `/docs` → Save，约 1–10 分钟生效。

- 产品介绍：`https://siroccowind.github.io/habit-bubbles/`
- 项目复盘：`https://siroccowind.github.io/habit-bubbles/retrospective-2026-11-10.html`
- 在线演示：`https://siroccowind.github.io/habit-bubbles/demo/`
- 旧「界面预览」链接会自动跳到产品介绍的演示区。

> Pages 站点始终对公网开放（即使仓库设为 private）。若不想公开复盘第 07 节的自评原话，可删减该节或不开 Pages —— 别人仍可下载 HTML 用本地浏览器打开（页面自包含、零外部依赖）。仓库名或用户名不同时，把上面的链接和 `docs/index.html` 里的仓库地址改一下即可。
